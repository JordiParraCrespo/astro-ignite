# Implementation — restructure-starter-template-component-o

## Summary

Restructured `packages/templates/starter/src/components/` from four
overlapping buckets (`ui/`, `blocks/`, `sections/`, loose-root chrome)
into three: `ui/` for atoms, `common/` for cross-feature compositions,
and one folder per feature (`about/`, `blog/`, `contact/`, `legal/`,
`not-found/`, `projects/`). Renamed `Nav.astro` to
`common/Header.astro`, moved every loose-root chrome file into
`common/` (or `legal/` for `CookieBanner`), and collapsed
`sections/<page>/` into per-feature directories. Updated all
consumers — `BaseLayout.astro` plus every page (default-locale and
`[lang]/` parallels) — to import from the new paths. Removed the
registry `blocks/` tier (deleted
`packages/registry/blocks/not-found-state.astro` and dropped the
`registry:block` item from `registry.json`). Mirrored the same chrome
restructure into `packages/templates/docs/`, `apps/site/`, and
`apps/docs/` (T17-T19). The `apps/playground/` mirror (T20) was
deferred — see `notes.md`; the playground is regenerated by
`scaffold:test`. Updated `packages/templates/starter/AGENTS.md` and
`packages/registry/AGENTS.md`, added the changeset, and extended
`.prettierignore` for the new chrome paths.
