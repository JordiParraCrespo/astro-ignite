## Deviation from design — test framework choice

The design under "Files touched" calls for a **vitest** unit test at
`scripts/perf/run.test.mjs`. Vitest is only declared as a
`devDependency` in `packages/astro-ignite/` and
`packages/design-fetch/`; root `package.json` is **not** in this
change's `Files touched` list, so we can't legally add a root vitest
runner here. Two options were considered:

1. Use vitest anyway and rely on a root devDep — rejected, because
   that requires editing root `package.json` (out of scope) and adds a
   workspace-root dependency footprint this change does not justify.
2. Use node's built-in `node:test` (Node 22.22 ships it) — chosen.

The `scripts/perf/run.test.mjs` file uses `node:test` + `node:assert`,
so it runs via `node --test scripts/perf/run.test.mjs` without
touching root config. 11 assertions, all pass. The spirit of the
design — a fast unit test on the pure comparator that runs without
Chrome — is preserved; the framework name is the only deviation.

`pnpm test` (which is `pnpm -r --filter=!playground test`) does not
pick the test file up because there is no root-level runner.
Reviewer note: invoking `node --test scripts/perf/run.test.mjs`
directly is the verification path; the full suite (`pnpm test`)
continues to pass on its own.
