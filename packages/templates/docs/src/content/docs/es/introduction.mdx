## Qué no es

astro-ignite no es un framework. No existe un paquete npm en tiempo de ejecución llamado
`astro-ignite`. Tras generar el proyecto, el código es tuyo y puedes editar cualquier cosa. Expulsar
es gratis porque no hay nada que expulsar.

Tampoco es un CMS, un sistema de autenticación ni un starter de e-commerce. Es un bootstrap de sitio.
