## Hecho también para agentes

- Cada proyecto generado incluye un `AGENTS.md` (con un enlace simbólico `CLAUDE.md`) para que los agentes sigan las prácticas fijadas cuando editen tu sitio.
- Cada página de docs también se sirve como Markdown en `<ruta>.md`; `/llms.txt` indexa el sitio y `/llms-full.txt` contiene todo el corpus. Un menú "Usa esta página con IA" en cada página copia el Markdown o lo abre en un asistente.
- El registro de componentes sigue el esquema de registro de shadcn, así que cualquier átomo se instala en cualquier proyecto con `npx shadcn@latest add @astro-ignite/<nombre>`. No existe un comando `astro-ignite add` — el CLI solo hace bootstrap.

## Qué no es

astro-ignite no es un framework. El paquete `astro-ignite` en npm es un CLI para crear tu proyecto —
nunca acaba siendo una dependencia en runtime del sitio generado. Tras generar el proyecto, el código
es tuyo y puedes editar cualquier cosa. Expulsar es gratis porque no hay nada que expulsar.

Tampoco es un CMS, un sistema de autenticación ni un starter de e-commerce. Es un bootstrap de sitio.
